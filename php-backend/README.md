# راهنمای استقرار (Deployment) بسیار آسان برای هاست PHP و MySQL

این سیستم برای استقرار فوق‌العاده ساده روی هاست‌های لینوکسی اشتراکی یا سرورهای اختصاصی (cPanel، DirectAdmin، Plesk یا Ubuntu/CentOS Nginx/Apache) طراحی شده است:

### ویژگی‌های کلیدی:
1. **بدون نیاز به خرید استوریج ابری گران‌قیمت (S3 / Cloud Storage)**: تمامی تصاویر آپلود شده مستقیماً روی دیسک سیستم‌عامل لینوکس در پوشه `uploads/` ذخیره می‌شوند.
2. **پایگاه‌داده قدرتمند و سبک MySQL**: همراه با اسکریپت ساخت جدول‌ها (`schema.sql`).
3. **تولید خودکار رمز عبور مشتری بر اساس سال شمسی + نام کاربری** (مثلاً `1405username`).
4. **ورودی ادمین اولیه**: نام کاربری `admin` و رمز `admin` که ادمین به راحتی می‌تواند تغییر دهد.
5. **ارتباط دوطرفه و ریپلای روی پیام‌ها** برای هر پروژه بین مشتری و ادمین.

---

### مراحل راه‌اندازی در ۳ دقیقه:

#### مرحله ۱: ساخت دیتابیس
1. در پنل هاست خود (cPanel / DirectAdmin) به بخش **MySQL Databases** بروید.
2. یک دیتابیس جدید بسازید (مثلاً `safebox_db`) و یک یوزر دیتابیس با تمام دسترسی‌ها (All Privileges) به آن متصل کنید.
3. وارد **phpMyAdmin** شوید، دیتابیس را انتخاب کرده و از منوی **Import** فایل `schema.sql` را بارگذاری کنید.

#### مرحله ۲: تنظیم فایل config.php
فایل `config.php` را باز کنید و اطلاعات دیتابیس خود را وارد کنید:
```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'نام_دیتابیس_شما');
define('DB_USER', 'یوزر_دیتابیس_شما');
define('DB_PASS', 'رمز_دیتابیس_شما');
```

#### مرحله ۳: آپلود فایل‌ها و پوشه عکس‌ها
1. فایل‌های `api.php`، `config.php` و فایل‌های فرانت‌اند بیلد شده را در مسیر `public_html` آپلود کنید.
2. یک پوشه به نام `uploads` در همان مسیر ایجاد کرده و مجوز دسترسی آن را روی `755` قرار دهید:
```bash
chmod 755 uploads
```

تمام! سیستم آماده استفاده است.
اطلاعات ورود ادمین پیش‌فرض:
- **نام کاربری**: `admin`
- **کلمه عبور**: `admin`
